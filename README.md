#  A to Z 타이핑 챌린지 (A-Z Typing Challenge)

> A부터 Z까지의 알파벳을 누가 가장 빠르게 입력하는지 겨루는 웹 기반 타자 속도 측정 및 실시간 랭킹 게임입니다.

---

###  [웹에서 바로 플레이하기 (클릭)](https://a-z-challenge-51e89.web.app)
별도의 다운로드나 설치 없이 브라우저에서 바로 플레이하실 수 있습니다.

###  주요 기능
- **실시간 타이머**: 첫 타이핑 시작과 동시에 0.001초 단위 정밀 타이머 작동
- **실시간 랭킹 시스템**: Firebase Firestore를 활용한 글로벌 리더보드 순위표
- **Google 간편 로그인**: 구글 계정으로 로그인하여 본인의 최고 기록 저장
